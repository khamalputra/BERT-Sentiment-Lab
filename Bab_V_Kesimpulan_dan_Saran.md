### **5.1. Kesimpulan**

Berdasarkan hasil eksperimen empiris, pengujian statistik inferensial, analisis kesalahan linguistik, dan implementasi aplikasi web yang telah dilaksanakan guna menjawab seluruh pertanyaan penelitian (RQ1--RQ4), diperoleh kesimpulan sebagai berikut:

1. **Efektivitas Performa Prediktif Klasifikasi Teks (RQ1)**: Penerapan metode *End-to-End Fine-Tuning* (Model B) terbukti secara empiris jauh lebih efektif dibandingkan *Feature Extraction* (Model A) dalam tugas klasifikasi sentimen teks SST-2. Model B mencapai rerata **Accuracy $92{,}78\% \pm 0{,}71\%$**, **Precision $92{,}45\% \pm 1{,}04\%$**, **Recall $93{,}48\% \pm 2{,}16\%$**, dan **F1-Score $92{,}94\% \pm 0{,}79\%$**, mengungguli Model A yang hanya meraih rerata **Accuracy $86{,}05\% \pm 0{,}69\%$**, **Precision $84{,}51\% \pm 1{,}62\%$**, **Recall $88{,}96\% \pm 1{,}03\%$**, dan **F1-Score $86{,}66\% \pm 0{,}43\%$** (peningkatan rerata F1-Score sebesar **$+6{,}28\%$** dan akurasi sebesar **$+6{,}73\%$**).
2. **Signifikansi Statistik Inferensial dan Robustness (RQ2)**: Peningkatan performa prediktif Model B terbukti nyata, konsisten, dan signifikan secara statistik di seluruh metode pengujian inferensial:
   - **Uji McNemar**: Perbedaan proporsi kesalahan klasifikasi biner berpasangan ($N=872$) sangat signifikan secara statistik ($\chi^2 = 47{,}6701$, $p\text{-value} = 5{,}04 \times 10^{-12} < 0{,}0001$).
   - **Uji Wilcoxon Signed-Rank**: Pengujian berpasangan multi-seed ($n=6$) mengonfirmasi keunggulan F1-Score Model B secara stabil ($W = 21{,}0$, $p\text{-value} = 0{,}015625 < 0{,}05$).
   - **Bootstrap 95% Confidence Interval**: Rentang interval kepercayaan 95% untuk selisih F1-Score bernilai positif murni $[\mathbf{+5{,}48\%} \text{ s.d. } \mathbf{+9{,}64\%}]$ (Percentile Bootstrap 10.000 resamples).
   - **Cohen's d Effect Size**: Ukuran efek numerik mencapai $d = \mathbf{9{,}80}$ (jauh melampaui ambang batas *large effect* $d \ge 0{,}8$ Cohen 1988 / *Huge Effect* Sawilowsky 2009).
   - **Uji Sensitivitas Jackknife**: Pengujian *leave-one-out* pada 6 subset $5\text{-of-}6$ seed menghasilkan $W = 15{,}0$ dan $p\text{-value} = 0{,}03125 < 0{,}05$ pada seluruh subset, menegaskan bahwa kesimpulan bersifat *robust* murni dan tidak peka terhadap pencilan seed tunggal.
3. **Kompromi Sumber Daya Komputasi dan Efisiensi Memory (RQ3)**: Ditinjau dari efisiensi komputasi inferensi production, alokasi memori VRAM GPU Model B dan Model A terbukti **praktis setara dan identik** dengan selisih alokasi terpakai hanya sebesar **$-4{,}05\text{ MB}$** ($<0{,}15\%$) ($3173{,}13\text{ MB}$ vs $3177{,}18\text{ MB}$ *Peak Allocated VRAM*; $3584{,}00\text{ MB}$ *Peak Reserved VRAM* untuk kedua model). Pada tahap akselerasi GPU NVIDIA A100 Primary, latensi inferensi kedua model hampir setara ($\sim 1{,}82\text{ ms}$ vs $1{,}83\text{ ms}$). Sementara pada lingkungan CPU Fallback Server (Railway Cloud 1-vCPU), latensi inferensi tetap sangat responsif ($24{,}65\text{ ms}$ untuk Model A dan $25{,}12\text{ ms}$ untuk Model B, rerata gabungan $\sim 24{,}88\text{ ms} < 100\text{ ms}$), membuktikan arsitektur *Dual-Backend Hybrid* yang dirancang mampu menjamin ketersediaan tinggi (*high availability*) tanpa pengorbanan responsivitas yang berarti.
4. **Ketahanan Linguistik Terhadap Fenomena Kompleks**: Model B menunjukkan keunggulan mencolok pada struktur kalimat kompleks, khususnya pada kategori **Review Panjang ($>40$ token)** dengan peningkatan akurasi **$+16{,}0\%$** ($94{,}0\%$ vs $78{,}0\%$) serta kategori **Negasi Biner** dengan peningkatan akurasi **$+13{,}3\%$** ($93{,}1\%$ vs $79{,}8\%$), karena seluruh bobot perantian *Self-Attention* disesuaikan secara dinamis untuk menangkap ketergantungan konteks jarak jauh.
5. **Implementasi Aplikasi Web Komparator Real-Time (RQ4)**: Produk aplikasi web *BERT Sentiment Lab* berhasil diimplementasikan 100% menggunakan arsitektur FastAPI (backend REST API) dan React 18 / Vite (frontend PWA) dengan dukungan Progressive Web App (*service worker*), sistem autentikasi RBAC, *Theme Toggle Switcher* (Dark/Light Mode), serta *API Rate Limiting* (10 request/menit). Pengujian kelayakan sistem menunjukkan cakupan kode (*code coverage*) backend sebesar **$86{,}5\%$** (15/15 *test cases pass*), pengalihan *failover* otomatis GPU $\to$ CPU dalam waktu **$1{,}24\text{ detik}$**, serta tingkat kepuasan kebolehgunaan antarmuka meraih skor **SUS $82{,}50$** (*Grade A / Excellent*) dari 10 responden.

### **5.2. Saran**

Berdasarkan pengalaman eksperimen dan keterbatasan penelitian yang ditemukan pada Sub-bab 4.6, disarankan beberapa hal terarah untuk pengembangan penelitian selanjutnya:

1. **Eksplorasi Arsitektur Model Transformer Terkini**: Penelitian selanjutnya disarankan untuk membandingkan model BERT dengan arsitektur Transformer yang lebih baru seperti RoBERTa, DeBERTa-v3, atau model berukuran ringkas (*compact models*) seperti DistilBERT dan ALBERT untuk mengevaluasi kompromi efisiensi latensi vs akurasi pada perangkat bersumber daya terbatas.
2. **Pengembangan Dataset Multi-Domain Berbahasa Indonesia**: Penelitian ini terbatas pada dataset SST-2 berbahasa Inggris. Disarankan agar penelitian berikutnya menerapkan metode *fine-tuning* pada dataset ulasan publik berbahasa Indonesia (misalnya dataset ulasan produk e-commerce, aplikasi digital, atau media sosial) dengan penanganan bahasa gaul (*slang*), kosa kata lokal, dan kode campuran (*code-switching*).
3. **Penerapan Teknik Kuantisasi dan Distilasi Model**: Untuk mempercepat inferensi di perangkat bersumber daya terbatas (*edge devices / mobile application*), peneliti selanjutnya disarankan menerapkan teknik kuantisasi bobot (*INT8 / FP16 Quantization*) atau *Knowledge Distillation* pada model hasil *fine-tuning*.
4. **Ekspansi Jumlah Random Seed Pelatihan**: Penelitian selanjutnya disarankan untuk memperluas jumlah *random seed* pelatihan menjadi minimal $n = 15$ atau $n = 30$ guna meningkatkan kekuatan statistik (*statistical power*) uji non-parametrik serta memungkinkan analisis kurva estimasi parametrik yang lebih representatif terhadap variasi stokastik inisialisasi bobot deep learning.
5. **Perluasan Ruang Label Tugas Klasifikasi**: Pengembangan lebih lanjut dapat memperluas cakupan tugas klasifikasi dari sentimen biner ke sentimen multikelas (misalnya rating skala 1--5 bintang) atau analisis sentimen berbasis aspek (*aspect-based sentiment analysis*) untuk menguji ketahanan model dalam skenario bisnis yang lebih kompleks.
6. **Optimasi Hyperparameter Secara Ekstensif**: Penelitian mendatang dapat melakukan pencarian *hyperparameter* secara ekstensif menggunakan metode *Grid Search* atau *Bayesian Optimization* untuk menemukan kombinasi optimal *learning rate*, *batch size*, dan *warmup ratio* yang dapat menghasilkan performa prediktif lebih tinggi.
7. **Pengujian UAT Skala Luas dan Stress Testing**: Evaluasi kebolehgunaan antarmuka aplikasi web disarankan untuk melibatkan responden dalam jumlah yang lebih besar ($N \ge 30$), dengan durasi pengujian yang lebih panjang (2--4 minggu) serta eksekusi pengujian beban puncak (*stress testing / load testing*) untuk mengukur ketahanan sistem terhadap lonjakan trafik pengguna secara simultan.
8. **Peningkatan Kapasitas Throughput Server Cadangan**: Untuk meningkatkan kapasitas *throughput* server cadangan CPU Fallback, penelitian lanjutan dapat mengimplementasikan lapisan *caching* prediksi (seperti Redis Cache) atau memanfaatkan arsitektur *serverless* (seperti AWS Lambda atau Google Cloud Functions) sebagai backend cadangan guna menangani lonjakan permintaan inferensi secara elastis.

### **5.3. Penutup dan Refleksi Akhir**

Secara keseluruhan, penelitian ini telah memberikan kontribusi empiris dan praktis yang solid dalam perbandingan strategi adaptasi model BERT untuk klasifikasi sentimen teks, yang dibuktikan melalui validasi statistik inferensial komprehensif serta wujud nyata produk aplikasi web *BERT Sentiment Lab* yang dapat diakses secara publik. Diharapkan temuan empiris, arsitektur *Dual-Backend Hybrid*, dan produk aplikasi web yang dihasilkan dapat menjadi rujukan ilmiah yang berguna bagi pengembangan sistem Pemrosesan Bahasa Alami (NLP) berbasis arsitektur Transformer di lingkungan akademik maupun industri.
